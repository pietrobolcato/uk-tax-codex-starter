# UK Self Assessment — Codex starter workspace

This is a clean, unpopulated workspace for collaborating with Codex on a UK Self Assessment return. It contains process guidance and blank schemas only. It is not tax advice and does not contain another taxpayer's facts, documents, calculations, identifiers, or filing credentials.

## Start here

1. Copy this folder and rename it for the relevant tax year.
2. Put untouched source exports and statements in `inbox/`.
3. Give Codex the text in `HANDOFF_PROMPT.md`.
4. Work through `WHAT_TO_GET.md` one batch at a time.
5. Store normalized data in the blank ledgers under `workpapers/templates/`.
6. Put only reviewed filing outputs and receipts in `filing/`.

## Workflow

`source evidence → normalized ledgers → reconciliations → tax analysis → scenario comparison → filing map → reviewed draft → authorised submission → receipt`

For rules, rates, deadlines, form boxes, and software behaviour, verify the position for the relevant tax year using current HMRC guidance. Do not copy conclusions from another person's return.

## Deliberately excluded

- Completed returns, calculations, tax-software files, screenshots, and receipts
- Names, addresses, UTRs, National Insurance numbers, account identifiers, employer details, and travel history
- Income, gains, tax, balances, transactions, holdings, refunds, and other populated financial figures
- Passwords, Government Gateway credentials, private keys, API tokens, and seed phrases
